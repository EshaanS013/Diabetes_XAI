# AWS Setup Notes (optional)

Student AWS credits may be available (NMIMS-domain and/or personal). Optional for Phase-1 training.

## Security rules

1. Enable MFA on root
2. Do **not** create root access keys
3. Use IAM users/roles with least privilege
4. Store secrets outside git
5. Configure billing alarms / budgets
6. Prefer CPU instances for these tabular models unless profiling shows otherwise

Phase-1 can and should run locally first.
